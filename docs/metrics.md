# 指标定义与人工参照带

本页把 `deslopkit` 报出的每个数字讲清楚：怎么算、为什么算它、以及**参照带从哪来**。
所有指标都由 `deslopkit.metrics` 这一处实现，第三方可以用同样代码复算报告里的每个数。

## 1. 指标清单

| 指标 | 定义 | 为什么要看它 |
|---|---|---|
| 汉字数 | `[\u4e00-\u9fff]` 计数，不含标点/数字/空格 | 字数口径统一（避免「Word 字符数」与「纯汉字」混用） |
| 句数 / 平均句长 / 最短最长句 | 以 `。！？!?…` 切句，句长＝汉字数 | 句长分布是检测器实际使用的两个形状特征之一 |
| **句长 CV** | 句长标准差 ÷ 均值 | 越低越像「模具」；模板化文本常低于 0.51 |
| **段长 CV** | 段长标准差 ÷ 均值 | 段落普遍等长＝「每段一个要点」的机器节奏 |
| ≤8 字短句占比 | 汉字数 ≤8 的句子 / 总句数 | 人写长文会有呼吸差；模型稿短句近乎为零 |
| 4-gram 重复率 | 1 − 唯一 4-gram / 总 4-gram | 资料拼接、注水、同义反复 |
| 4-gram 高频片段 | 出现 ≥2 次的 4-gram Top-10 | 直接指出「哪几句在转圈」 |
| 重复整句 | 汉字 ≥8 且出现 ≥2 次的句子 | 跨段复制粘贴；正常写作极少出现 |
| 长定语句 | 含 ≥4 个「的」的句子数 | 模型偏好的「多重定语」长句 |
| 修辞破折号 `——` | 独立使用的破折号计数 | 散文里最硬的机器痕迹之一 |
| **连接号 `—`** | 单独统计（年段、链式表述、标准号） | **国标本义用法，不是痕迹**，因此与上者分开 |
| 中文冒号 / 提示性冒号 | `：` 总数 / 其中后接非引语的数量 | 「核心是：」这类提示性冒号是模板腔 |
| 半/全角混用 | 半角 `:`、半角引号计数 | 复制粘贴与模型输出的接缝 |

## 2. 参照带（同语域人工样本实测）

参照带不是拍脑袋的阈值，而是拿**同语域、真人撰写**的公开样本量出来的下限：

| 语域 | 句长 CV ≥ | 段长 CV ≥ | ≤8 字短句占比 ≥ | 备注 |
|---|---|---|---|---|
| `zh-gov` 中文公文/课题报告 | 0.45 | 0.35 | 1.5% | 公文本身较规整，下限低于散文 |
| `zh-academic` 中文学术 | 0.45 | 0.35 | 1.5% | 结果段句式统一属正常，只看是否「全篇一个模子」 |
| `zh-forum` 中文网帖 | 0.50 | 0.40 | 5.0% | 活人感要求最高 |
| `en-academic` | 0.45 | 0.35 | 3.0% | 与中文同理 |
| `en-essay` | 0.55 | 0.45 | 6.0% | 对应英文散文/博客类规则集的口径 |

**用法**：`deslopkit audit` 会直接把实测值与下限并排打印。落在下限以下说明句式或段落偏模具化，
是本工具要动手的地方；远高于下限说明形状已经很「人」，此时**不要为了指标好看去动文本**。

## 3. 自建参照带（推荐在自己的领域做一次）

参照带与体裁强相关，建议用你自己领域的真人样本校准：

1. 收集 3–5 份同语域、确认为真人撰写的材料（政策原文、期刊论文、教案、已发表报道）。
2. 抽成纯文本后逐个跑 `deslopkit audit <file> --register <你的语域> --json out.json`。
3. 取各指标的**中位数**作为下限，写进 `register.py` 对应画像的 `sent_cv_min` / `para_cv_min` /
   `short_sent_ratio_min`。
4. 在 PR 里附上样本来源与计算过程；参照带属于可争议参数，需要证据。

## 4. 常见误读

* **CV 越低越差，但 CV 不是越高越好。** 把一句话切成五段能刷高 CV，那是造假不是改善。
  因此闸门检查的是「不下降」，不是「必须上升」。
* **短句占比可以靠「一句成段」提升**，但只有在那一句确实需要停一下时才成立；
  为指标服务地拆句，会被 `no new repeated sentences` 与人工复核抓住。
* **4-gram 重复率高不必然是坏事。** 一份关于「教师智能素养」的报告里，
  「教师智能素养」高频出现是术语一致，不是注水。工具会列出高频片段，由人判断是术语还是转圈。
* **标点指纹里，只有修辞破折号与提示性冒号算痕迹**；年段 `2026—2029`、链式 `学—教—研—评`、
  标准号 `T 0646—2022` 一律不动。

## 5. 报告里的数字怎么复算

```bash
deslopkit audit 你的文件.txt --register zh-gov --json audit.json
python - <<'PY'
import json; d = json.load(open('audit.json'))[0]
print(d['metrics']['sent_cv'], d['metrics']['para_cv'], d['metrics']['short_sentence_ratio'])
PY
```

JSON 里包含全部原始计数（含标点指纹与高频片段），因此任何一处结论都可以被复核或推翻。

## 6. 为什么不做「困惑度」指标

有些工具用语言模型困惑度（perplexity）当作「像不像人写」的代理指标。本项目不用，原因有三：
① 它依赖具体模型与权重，换模型即换结论，违背可复算原则；
② 中文公文/学术的困惑度天然偏低，会与体裁混淆；
③ 它奖励「意外词」，而这恰恰是学术写作要避免的（术语必须稳定）。
